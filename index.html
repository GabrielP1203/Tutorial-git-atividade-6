O que é o Git?

O Git é um sistema de controle de versão distribuído gratuito e de código aberto. Ele permite que você acompanhe o histórico de alterações do seu código, trabalhe em equipe de forma organizada e recupere versões anteriores se algo der errado.

O Git é um sistema de controle de versão distribuído e de código aberto, criado em 2005 por Linus Torvalds. Ele serve para rastrear, registrar e gerenciar todas as alterações feitas no código-fonte de um projeto ao longo do tempo.

Git vs. GitHub (Diferença importante)

Git: É o software instalado no seu computador que gerencia as versões do código localmente.

GitHub: É uma plataforma web (hospedada na nuvem) que usa o Git por trás para armazenar, visualizar e facilitar a colaboração em projetos online.

Principais Comandos do Git

Comando O que faz? Exemplo de Uso
git init Inicializa um repositório Git vazio na pasta atual. git init
git add Prepara (adiciona) os arquivos modificados para o próximo registro. git add .
git commit Salva oficialmente as alterações preparadas no histórico local. git commit -m "Meu primeiro commit"
git status Mostra o estado atual dos arquivos (modificados, prontos ou não rastreados). git status
git push Envia os commits locais para o repositório remoto (ex: GitHub). git push origin main
